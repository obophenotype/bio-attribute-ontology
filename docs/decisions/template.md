## Question

The choice to be made, in one or two sentences.

## Context

What each resource offers for the entity, with identifiers and labels as
published. What OBA does today, with counts and example terms. How downstream
consumers (e.g. Translator NodeNorm, EFO, GWAS Catalog) currently treat the
identifiers, if it matters.

## Options

The realistic alternatives, with what each would mean for OBA and for others.

## Decision

The answer (or, while `proposed`, the recommendation), stated as a rule an
editor can apply to a new case.

## Consequences

- For OBA: terms that change, QC checks, imports.
- For other ontologies: requests to make of them, mappings to publish.
- For downstream consumers.

## Open questions

Cases the rule does not settle yet.
