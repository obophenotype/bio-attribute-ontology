# OBA Mappings

The curated VT, EFO and LOINC mappings (`oba-vt.sssom.tsv`, `oba-efo.sssom.tsv`, `oba-loinc.sssom.tsv`) and their `*-mapping-exclusions.sssom.tsv` counterparts are edited here directly, through pull requests. They used to be synced from Google Sheets; the sheets are no longer used (see [#479](https://github.com/obophenotype/bio-attribute-ontology/issues/479)).

`oba-efo.sssom.tsv` and `oba-loinc.sssom.tsv` use CRLF line endings. Preserve them when editing and check `git diff --stat` before committing.
